# Self-Healing System (Python)

A lightweight decorator that gives any function automatic retry, error logging, and self-healing behavior. Inspired by real-world resilient system design.

## 🔥 Features
- Automatic retry on failure
- Timestamped error logs
- Clean, reusable decorator
- Simulates unstable operations
- Simple, elegant, production-friendly

## ▶️ How to Run
python3 self_healing.py
